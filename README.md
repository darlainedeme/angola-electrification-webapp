# Angola Electrification — Compact Response Dashboard

Interactive dashboard accompanying the World Bank / IFC response to the MINEA Energy Compact (April 2026 revision). Shows three access target scenarios (53%, 60%, 70% by 2030) with cluster-level granularity from OnSSET / GEP V.3 Scenario C.

## What it shows

- **Overview** — three scenario cards with headline cost, connections, and modality share; side-by-side Compact comparison.
- **Provincial map** — 18 provinces shown as cost-weighted centroids; optional cluster-point overlay (newly selected clusters only, marker-clustered).
- **Modality breakdown** — stacked bars for connections and cost, plus the underlying numbers.
- **Staged delivery** — four-track program timeline for 60% and 70% scenarios.
- **Compact response** — reconciled critique table.

Scenario state is URL-shareable (e.g. `?scenario=S70`).

## Deploy to GitHub Pages

1. Create a new repo (public): `angola-electrification`.
2. Copy this folder's contents to the repo root.
3. Push to `main`.
4. In repo Settings → Pages: source = `main` branch, folder = `/ (root)`.
5. Wait ~30 seconds for the first build, then visit `https://<user>.github.io/angola-electrification/`.

No build step. Single static site, ~1.6MB total payload.

|---|---|---|
| `data/summary.json` | ~3 KB | `cost_summary.csv`, `modality_breakdown.csv` |

| `data/staged.json` | ~2 KB | `staged_costs.csv` |
| `data/critique.json` | ~2 KB | `compact_critique_table.csv` |

| `data/clusters/S70.json` | ~820 KB | newly selected clusters (21,948) |

Cluster files contain points only (no polygons) — per-cluster centroid plus mode, connections, cost.

## Rebuild data

The data files are generated by the build pipeline in the analysis repo. To refresh:

```
cd /path/to/AGO3
python angola_compact_v4/code/02_build.py
python angola_compact_v4/code/04_build_dashboard_data.py
```

Open http://localhost:8000

## Stack

- Vanilla JS, no build tooling
- Leaflet 1.9.4 + Leaflet.markercluster 1.5.3 (CDN)
- Chart.js 4.4.0 (CDN)
- CartoDB Positron basemap

## Methodology

See `MINEA_compact_comments_2026-05-25.docx` and `METHODOLOGY.md` in the analysis repo.

Headline: WB-reconciled 51% baseline (vs Compact's literal 45%); $1,437/conn blended grid cost (ENDE LOTES, 17 lots, post-11% add-ons); $282/conn SHS (OnSSET Tier 1 mid). Mini-grid clusters reclassified to SHS per the plan's no-MG rule.
